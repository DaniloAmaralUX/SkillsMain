# Requisitos e Protótipos

Crie um protótipo navegável com requisitos e fluxos a partir de uma ideia ou de um documento no chat da IDE. [Experimente o viewer](https://daniloamaralux.github.io/requisitos-e-prototipos/).

## Instalar no projeto

Use Node.js 22.20 ou mais recente para instalar com npx. Execute o comando na pasta do projeto e selecione o agente da sua IDE.

```sh
npx skills@1.9.0 add https://github.com/DaniloAmaralUX/SkillsMain/tree/requisitos-v1.0.0-rc.4 --skill requisitos-e-prototipos
```

Abra uma nova conversa e peça “Use a skill requisitos-e-prototipos para criar um protótipo de pedido de almoço com horário de retirada”.

Com a skill instalada, o agente usa Python 3.10+ e Node.js 18+ para gerar e verificar o protótipo. O HTML gerado abre no navegador. [Instruções da skill](skills/requisitos-e-prototipos/SKILL.md).
